# CodeAlpha_ImageGallery

Responsive image gallery built with HTML, CSS and vanilla JavaScript (CodeAlpha Frontend Internship – Task 1).

## Features
- CSS Grid layout, responsive for desktop, tablet and mobile
- Lightbox view with Next / Previous buttons
- Keyboard (← → Esc) and touch-swipe navigation
- Hover zoom + overlay effects, smooth transitions
- Bonus: category filters (Nature, City, Animals, Tech)

## Run
Open `index.html` in a browser (internet needed for demo images from picsum.photos).
To use your own images, edit the `photos` array in `script.js`.
